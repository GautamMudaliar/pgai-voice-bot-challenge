# PGAI Voice Bot Challenge

An automated voice bot that calls the assessment test line
(`+1-805-439-8008`), plays a "patient" persona through a phone conversation
with the clinic's AI agent, records both sides of the call, and analyzes
the transcript for bugs.

See `ARCHITECTURE.md` for the design reasoning behind these choices.

## Requirements

- Python 3.10+
- An ElevenLabs account with:
  - Conversational AI (Agents Platform) access
  - A Twilio account connected as a phone number provider (see
    [ElevenLabs' Twilio native integration docs](https://elevenlabs.io/docs/eleven-agents/phone-numbers/twilio-integration/native-integration))
  - A Twilio number imported into ElevenLabs, which is the number your bot
    calls FROM
- An Anthropic API key (used only for the post-call bug analysis pass)

## Setup

1. Clone the repo and install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Copy the environment template and fill in your credentials:

   ```bash
   cp .env.example .env
   ```

3. Create the base "patient caller" agent (one-time):

   ```bash
   python -m src.setup_agent
   ```

   Copy the printed `agent_id` into `ELEVENLABS_AGENT_ID` in your `.env`.

## Running calls

Run every scenario defined in `src/scenarios.py` (recommended, this is the
full test suite used for the submission):

```bash
python -m src.call_runner --all
```

Or run a single scenario by id, useful while iterating:

```bash
python -m src.call_runner --scenario 09_sunday_edge_case
```

Each call's transcript (`.transcript.json` and a readable `.transcript.txt`)
and audio recording (`.mp3`) are saved to `recordings/`.

## Bug analysis

After running calls, generate a draft bug report:

```bash
python -m src.bug_analyzer
```

This writes `bug_report.md` at the repo root. Treat it as a first pass, it's
meant to speed up review, not replace listening to the actual calls.

## Adding new scenarios

Add a new `Scenario(...)` entry to `SCENARIOS` in `src/scenarios.py`. No
other code needs to change, `call_runner.py` and `bug_analyzer.py` both pick
up new scenarios automatically.

## Repo layout

```
src/
  config.py           # env var loading
  elevenlabs_client.py # outbound call, transcript, and audio retrieval
  scenarios.py         # patient persona / scenario definitions
  setup_agent.py        # one-time ElevenLabs agent creation
  call_runner.py        # places calls, saves transcripts + audio
  bug_analyzer.py       # Claude-based bug detection pass over transcripts
recordings/              # transcripts (.json/.txt) and audio (.mp3) per call
bug_report.md             # generated by bug_analyzer.py
.env.example
requirements.txt
ARCHITECTURE.md
```
